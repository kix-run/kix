Three new experimental packages provision PostgreSQL databases and roles with [DB Operator](https://github.com/db-operator/db-operator) 2.47.0: `db-operator`, `db-operator-instance`, and `db-operator-database`. `db-operator` deploys the `kinda.rocks` custom resource definitions, the controller, and the admission webhook server with a `cert-manager` certificate. `db-operator-instance` creates a `DbInstance` that connects the operator to a PostgreSQL server using an admin `Secret`. `db-operator-database` creates a PostgreSQL database and login role for an application, and the operator writes a generated password into a `Secret` in the application's namespace. `db-operator-database` implements `kix.contracts.postgresDatabase` (like `cnpg-database` and `stackgres-database`), so packages that take a `database` dependency, such as `metabase`, work with it without changes. When network policies are enabled, Kix allows traffic from the Kubernetes API server to the webhook and from the operator and applications to in-cluster PostgreSQL servers. See the "Create databases with DB Operator" how-to guide to get started.
