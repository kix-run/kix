`grafana` runs Grafana 13.3.1 (was 13.1.8), which fixes the 17 CVEs listed in Grafana's 13.3.0 and 13.3.1 release notes, among them CVE-2026-102589 and CVE-2026-14242. Grafana 13.3 no longer ships the deprecated Parca data source, and the package turns plugin installs off, so a Parca data source stops working after the deploy with no error. Upstream ends support for the Parca plugin on 2 January 2027. If you use a Parca data source, keep the previous Kix release until you have moved those dashboards to another profiling data source, or removed them. The first deploy restarts the Grafana pod, and Grafana updates its database when it starts. Grafana 13.3 keeps its Prometheus, Loki, Tempo, and other data source plugins and its canvas panel in a separate folder of the image, so the package no longer mounts an empty folder there. The Elasticsearch and Zipkin data sources, which that empty folder hid, now load too. In our test, Grafana 13.1.8 could still read a database that 13.3.1 had updated, but upstream does not promise this. Copy `grafana.db` before you deploy if you may need to go back.
