Kix's error messages and command output are shorter and easier to act on. An evaluation error no longer starts with the internal command line, the warning about uncommitted files in Git, or stack frames inside the Kix library. A Kix error with an id, such as `[K0549]`, now stands alone. `[K0549]` now lists every old package name a cluster uses at once, and also covers `packages.stable.<name>` for an experimental package. The `[K2377]` refusal now gives the package's actual name. Setting `package = ./dir` without `import` now says to add `import`. `kix check` now lists the scorecard findings under its table, and `-v` adds the info findings. With `-o json`, the `scorecard` entry carries them as `findings`. `kix drift` lists only the resources that are not in sync, unless you pass `-v`. `kix diff`, `kix status`, and `kix gc` put the objects of other Kix clusters on one line. `kix plan` shows the line that differs when a long text field drifted. A failed apply ends with the apiserver's message alone. `kix upgrade --to` with a prerelease explains how to try it. Progress lines no longer write terminal control codes when output goes to a file or a pipe.
