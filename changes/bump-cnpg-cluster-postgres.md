`cnpg-cluster` now runs PostgreSQL 18.7 instead of 18.6. The release fixes 52 CVEs that the 18.6 release notes do not name, and the header lists them. The first deploy after you upgrade replaces each PostgreSQL pod, one at a time, and keeps the data. Upstream also says earlier bugs can have corrupted some indexes, and that 18.7 does not repair existing ones. REINDEX any btree index on a `bpchar` column, and any `pg_trgm` GiST index created with `gist_trgm_ops`. You do not need to change your definition.
