`kix status` now reports an object of the build that is being deleted as `deleting` (in place of `not ready` or `changed`), with when deletion started and the finalizers that hold it, and lists objects that left the build and are still being deleted under `Left the build, still being deleted`. In `-o json`, `problems` can contain `deleting`, each resource gains `deleting_since` and `finalizers`, each cluster gains `leaving`, and every `summary` gains `deleting` and `leaving`. `kix plan --prune` now lists each delete that will wait for finalizers or for an object already being deleted, and warns when the controller that a custom resource's kind names (`controller` on `scope.mkCRD`) is not ready, not on the cluster, or cannot be read. The warning does not change the exit code. In the plan document, `prune` entries gain `finalizers`, `deleting_since`, and `controllers`. `kix gc` gains `--timeout`, which sets how long it waits for each deleted object to be gone while no finalizer is removed (default 3 minutes, at most 5 minutes in total for each object).
