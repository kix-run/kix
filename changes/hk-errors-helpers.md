In custom packages that call `kix.mergeGuarded`, `kix.mergeEnv`, `kix.guardArgs`, or `kix.storage.mkClasses`, remove `who` and pass `inherit scope;`. Passing `who` now stops evaluation with an error. `kix.mergeGuarded` also renames `what` to `option`, the name the other two helpers use. Passing `what` stops evaluation with error K0998, so rename it to `option`. Cluster definitions that use only built-in packages need no changes. These helpers now raise errors through `scope.fail`, and `scope.fail` now records `package` on built-in packages as well as `instance`, so `kix check -o json` includes both fields. `kix.mergeGuarded` also accepts an optional `object` attribute set, accepts `option = null` for overrides that do not come from an option, and now tells users to remove locked fields from the option they set. `kix.mergeEnv` accepts `option` (default `"env"`) to name the option in errors, and its `owned` entries accept `reason` instead of `from` when a package rejects an environment variable outright. An `owned` entry without `fix` now tells users to remove the variable from that option. `kix.storage.mkClasses` takes `optionPath` without the `config.` prefix, such as `"classes"`.
