If you write custom packages that call `scope.requireMetricsApi`, return its result from the package's `warnings` function, because `scope.requireMetricsApi` now returns a list of warnings instead of `null`. Cluster definitions need no changes. Kix now shows warnings that were previously hidden whenever evaluation succeeded, including warnings from `cilium`, `descheduler`, `mayastor`, `plausible`, `rabbitmq-cluster`, and `spegel`. It also shows warnings when a custom resource references a Service address without declaring whether its pods connect to that Service (`factBehavior`), or when a package's `secrets` or `crds` folder contains a non-resource value. `kix graph`, `kix list images`, and `kix list resources` now print warnings to stderr, matching `kix build`, `kix plan`, and `kix deploy`. Bundles created with `kix bundle` include build warnings, so `kix plan --bundle`, `kix deploy --bundle`, `kix diff --bundle`, and `kix graph --bundle` print them too. Package `warnings` and `assertions` functions also now receive `clusterConfig`.
