When a deploy or rollback runs without `--prune`, the plan and deploy output now recommend `kix gc <cluster>` to delete leftover objects; previously they also suggested `kix deploy <cluster> --prune`, which would undo a rollback. `kix gc --full-scan` now attributes a `PackageInstance` resource to its package instance instead of `_cluster`. When `cluster.kubernetes.uid` does not match the connected cluster, the error aligns the two UIDs, lists connecting to the wrong cluster first, and no longer prints a `cluster.kubernetes.uid` snippet that could be copied to bind the definition to the wrong cluster. The `Plan:` summary line now includes reapplied unchanged objects (such as objects restored after a stopped deploy or under `--reconcile`) and updates that change only the deployment record, matching the `Objects:` count. When a stopped deploy leaves changes on an object, plans now report it only as modified instead of also counting it as a reapplied unchanged object.
