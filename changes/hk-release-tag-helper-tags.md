If you override an image tag on `cert-manager`, `cnpg-barman-cloud`, `envoy-gateway-controller`, `external-dns`, `external-secrets`, `infisical-operator`, `mayastor`, `reloader`, `snapshot-controller`, `tailscale`, `volsync`, or `zfs-localpv`, match upstream's `v` prefix (for example, `v1.21.3` for `cert-manager`, where upstream tags start with `v`). These packages now reject image tags during evaluation when a tag adds or omits upstream's leading `v`, instead of letting pods fail to pull an image tag that upstream does not publish. Every package that checks image tags against its bundled CRDs or RBAC now reports mismatches in the same format, and `mayastor` now names the specific component image option instead of always reporting `image.tag`.
