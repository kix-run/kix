Packages that check an image tag against the release their CRDs or RBAC rules come from now report a mismatch with the same message, and accept the tag with or without a leading `v`, so an image rebuilt with another tag form passes. `kubevirt`, `cdi`, `prometheus-operator`, and `velero` used to require the `v`, and `cnpg-operator` and `rabbitmq-operator` used to refuse it. `mayastor` now names the image option that holds the wrong tag instead of always naming `image.tag`. `arc` still refuses a leading `v`, because its controller cannot parse a version label that starts with one.
