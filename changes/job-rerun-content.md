A Job with `kix.run/rerun: on-change` now runs again only when its own manifest changes, including the `checksum/*` annotations on its pod template. Before, it also ran again when anything it depends on changed, such as a label on its namespace or a CoreDNS setting. Kix's packages now put a `checksum/<name>` annotation on each such Job for what it reads, so the `stackgres-database` and `clickhouse-database` bootstrap Jobs still run again when the password's SOPS file, the package options, or the database server change, and the webhook checks and `kix.healthCheck` probes run again when what they check changes. If one of your own packages has a Job with `kix.run/rerun` that reads a Secret or a ConfigMap, add `"checksum/<name>" = <resource>.out.contentHash` to the Job's pod template annotations. Without it, the Job does not run again when that object changes.
