Before upgrading, update RBAC for every Kubernetes account that runs Kix commands (and for the Kix operator's ServiceAccount, if you use operator mode), and upgrade the Kix operator before running Kix against its clusters. Kix now installs and updates its four CustomResourceDefinitions (`activations.kix.run`, `packageinstances.kix.run`, `activationheads.kix.run`, and `packageinstancerevisions.kix.run`) before modifying a cluster. Every account that runs `kix deploy`, `kix rollback`, `kix gc`, or `kix migrate domain`, as well as the Kix operator's ServiceAccount, needs `get` on those four CRDs, `get`, `list`, `create`, and `update` on `activationheads.kix.run`, `get`, `list`, `create`, and `delete` on `packageinstancerevisions.kix.run`, and `patch` on `packageinstancerevisions/status`. The account that first runs one of those commands (or the operator) after upgrading also needs `create` on `customresourcedefinitions` to install any missing CRDs, and needs `update` on `customresourcedefinitions` when a later Kix version updates those CRD schemas. Accounts that run `kix plan` need `list` on `activationheads.kix.run` and `packageinstancerevisions.kix.run`, plus either cluster-wide `list` or namespaced `get` on every resource kind in the build and in the cluster's revisions.

Commands stop with `[K9557]` before changing anything when these permissions are missing, or when `--operator` is passed before the operator reports `requests`, `head-lock`, and `revisions` in `kix.run/operator-features` on `activations.kix.run`. Commands that modify a Kix cluster also stop with `[K9557]` before planning if that cluster's current, queued, or deploying deployment record was submitted to an operator and `activations.kix.run` does not list `revisions` in `kix.run/operator-features`. That happens when an older operator (including Kix 0.9 or earlier) is still installed, or when the operator was uninstalled. If you uninstalled the operator, run `kix deploy <cluster> --operator-removed` once. Other Kix clusters on the same Kubernetes cluster are unaffected.
