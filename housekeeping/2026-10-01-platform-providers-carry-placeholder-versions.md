# 2026-10-01 · `kix/packages/cilium`, `kix/lib/flavors` · Platform providers report a version that is not the one running.

`cilium` has `meta.version = "1.19.6"`, the chart version, but only its chart delivery installs that chart. When the environment installed Cilium (RKE2's bundled chart, or `cluster.network.environmentCilium.helmChartConfig = null`) the running version is whatever the environment chose, and `meta.compatibleWith` still compares against 1.19.6. Imports such as `platform-dns` carry no version at all, so `kix/lib/meta.nix` warns and skips any version range on them. See doc 155 §5.3.
