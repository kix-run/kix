# 2026-11-23 · `kix/lib/eval/validate-keys.nix` · `cedesData` splits `kix.run/cede-fields` at every comma, including commas inside a list selector.

The library joins the declared `ownership.cede` paths with commas (`kix/lib/core/resource.nix`), and `cedesData` splits them again with `splitList`. The Rust reader (`split_outside` in `cli/kix/src/cluster/apply/ssa.rs`) keeps `[port=53,protocol="UDP"]` in one piece. `cedesData` only asks whether a path starts with `data`, `binaryData`, or `stringData`. A piece cut from inside a selector can still start with one of those words: `spec.items[name="a",data=1]` yields `data=1]`. The resource is then treated as ceding its data, and the key checks for it are skipped. One fix is to split outside brackets in Nix as Rust does. Another is to give the check the declared list before it is joined, so there is one reader of the joined form.
