# 2026-10-02 · `kix/packages/grafana` · Grafana runs one pod because the package wires no high-availability setup.

The Deployment carries `availability.max = "none"` and `replicas = 1` at every availability level. More pods would need alerting HA (memberlist peers through `ha_peers` with a headless Service and a 9094 port, or `ha_redis_address`), an external database in place of SQLite, and no ReadWriteOnce data claim. Without them each pod sends its own alert notifications, and several pods write one SQLite file. A cluster that asks for `pod` or above gets a capped-workload warning and a single point of failure.
