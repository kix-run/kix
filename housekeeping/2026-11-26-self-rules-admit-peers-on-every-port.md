# 2026-11-26 · `kix/lib/plugins/netpol` · `mkSelfRules` allows peer pods to reach each other on every port.

`mkSelfRules { selector; }` accepts no port list in either the Cilium enforcer (`kix/packages/experimental/cilium/netpol-rules.nix`) or the standard `NetworkPolicy` enforcer (`kix/lib/plugins/netpol/standard.nix`). Both the automatic `StatefulSet` rule in `kix/lib/plugins/netpol/derive.nix` and the operator-pod policies in `alertmanager`, `clickhouse-keeper`, `clickhouse-cluster`, `stackgres-cluster`, `cnpg-cluster`, `kubevirt`, and `victoria-metrics-alert` therefore open every port between a workload's own pods. `derive.nix` does not know which ports a `StatefulSet` uses for peer traffic, whereas those packages know their peer ports and have no way to pass them.
