# 2026-10-03 · `kix/lib/meta.nix` · Package `assertions` receive no `clusterConfig`, so a refusal that depends on cluster capabilities must be a `throw` in `build`.

`evaluatePackageDiagnostics` passes `config`, `self`, and `deps` to a package's `assertions`, not `clusterConfig`. The falco package refuses clusters whose `cluster.capabilities` sets `daemonSets` or `privilegedContainers` to false, so it throws from its DaemonSet part instead (`kix/packages/falco/default.nix`). A unit test cannot read a throw's message, and the lib's own capability checks refuse the same clusters, so the test cannot tell which refusal fired. The package moved the check into `platform.nix` so the test can call it directly. mayastor reads `clusterConfig.cluster.nodes` in `build` for the same reason.
