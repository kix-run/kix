# 2026-10-03 · `cli/kix/src/eval/store_graph.rs` · Without a package index on the record, a live import marker joins every build package that lists it, including packages not yet on the cluster.

When the deployed record has no `status.packageIndex` (Kix 0.5 wrote none), `StoreGraph::synthesize` puts a live object under each build package listing its kind, namespace, and name, because one `secret-ref-*` marker can be listed by several packages. A package that is new in the build and imports an existing marker therefore gets that marker on the old side, and `kix diff` shows the package as updated rather than added. With an index, the marker goes only under the packages the deployed build listed it in.
