# 2026-10-02 · `kix/lib/vocab/compose.nix` `kix.options.ingress` · An instance cannot turn off a route its package exposes.

`kix.options.ingress` has `host` and `annotations` and nothing that turns the route off. For a package that calls `kix.expose` with the default `deriveHost = true`, the instance gets an Ingress or HTTPRoute at `<instance>.<cluster.domain>` whenever the cluster has an ingress controller or a gateway and a `cluster.domain`, so an instance that should stay internal is routed anyway. A package can opt out with `kix.expose { deriveHost = false; }`, which routes only an instance that sets `ingress.host`; Grafana does this, so its unauthenticated `/metrics` no longer depends on this gap. The cluster author still has no per-instance switch for the other packages.
