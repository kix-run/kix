# 2026-11-24 · `kix/lib/helm.nix` · A dependency's `out` value in chart `values` gives the chart's workloads no deploy order on that dependency.

`renderSpec` drops the string context of `values`, so `backendHost = backend.out.fqdn` renders the right text and adds no dependency. `importChart { deps = [ backend ]; }` adds network policy, but the chart's Deployment then depends only on the DNS provider and its generated policies. It comes after `Service/backend` only because the generated egress policy depends on that Service, and with `networkPolicy.enable = false` it has no edge on the backend at all. Nothing makes it wait for the backend's workload. Seen with `kix build` on a local test chart. `2026-10-02-import-chart-deps-has-no-user.md` says `deps` gives "the ordering", which is true only through the policy.
