# 2026-11-28 · `cli/kix-cli/src/commands/diff.rs` · `kix diff --from <snapshot dir>` of a cluster this Kix deployed likely shows every object as modified.

A manifest directory baseline is compared with `plan::diff_graphs` (`Compare::Builds`, diff.rs:307), which keeps the five graph notes. Kix no longer sends `kix.run/identity-hash`, `kix.run/depends-on`, `kix.run/package`, `kix.run/package-namespace`, or `kix.run/lifecycle`, so a `kix snapshot` of such a cluster lacks them while the new build has them. `StoreGraph::synthesize` then cannot match an object to its build manifest by identity hash, and `kix.run/package` and the other instance notes are not propagation paths, so each object reads as a real change. Found by reading the code, not by running it. Snapshots of clusters an older Kix deployed still carry the notes.
