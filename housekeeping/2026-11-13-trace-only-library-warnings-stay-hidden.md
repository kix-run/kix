# 2026-11-13 · `kix/lib/scope/validators.nix`, `kix/lib/scope/builders.nix` · Some library warnings exist only as `builtins.trace` lines, so Kix never shows them when the build succeeds.

`kix check` lists the warnings in the cluster's `diagnostics.warnings` (written to `kix-warnings.json`), but several warnings never reach that list. They are traced where they arise and nowhere else: the capability and role warnings in `scope/validators.nix` (for example the warning that `cluster.roles.loadBalancer.binding` is unset, so Kix skipped checking for a load balancer), the edge and interceptor warnings traced onto a workload's `outPath` in `scope/builders.nix`, the missing-DNS warning in `eval/instance.nix`, and the traces in `core/resource.nix`, `eval/auto.nix`, and `eval/view.nix`. They need a channel from resource construction into `_diagnostics`, which `v2_discussions/80_structured_diagnostics.md` sketches.
