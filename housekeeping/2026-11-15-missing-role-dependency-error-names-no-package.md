# 2026-11-15 · `kix/lib/eval/resolve.nix` · A missing role dependency tells the user to add an instance named after the role.

A package that takes a role as a required dependency and finds no provider fails with "dependency '<role>' has no matching instance in namespace '<ns>'" and suggests `instances.<ns>.<role>.package = packages.<package>;`. A role is found across the cluster, so the namespace and the instance name in that advice are wrong, and the message does not name the packages that claim the role. envoy-gateway and traefik avoid it by taking `gatewayApi ? null` and refusing with their own message (`kix/packages/experimental/gateway-api/require.nix`); a generic fix in resolve.nix could name the claimants from `availablePackages` and say that a `kix.mkImport` with `roles = [ "<role>" ]` also answers.
