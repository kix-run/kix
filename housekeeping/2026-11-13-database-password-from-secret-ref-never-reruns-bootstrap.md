# 2026-11-13 · `kix/packages/experimental/stackgres-database`, `clickhouse-database` · A changed password from a secret-ref does not run the bootstrap Job again.

The bootstrap Job carries `kix.run/rerun: on-change`, so it runs again when its own content changes. A password from a SOPS file changes its `kix.run/rerun-hash`, because the library folds in the `out.contentHash` of each Kix-built Secret the Job reads. A password from `packages.secret-ref` lives only in the cluster, so the build does not change when the site changes the Secret. The Job does not run again, and the database keeps the old password while the app reads the new one. Fixing it needs the deploy to read the live Secret, which no rerun rule does today.
