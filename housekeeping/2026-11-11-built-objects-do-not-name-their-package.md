# 2026-11-11 · `cli/kix-cli/src/commands/upgrade/` · A built object names its instance, never its package, so `kix upgrade` matches change records by instance name.

Change records name packages under `kix/packages/`, but a build carries only the instance name (`kix.run/package`, PackageInstance `spec.instanceName`). `kix list packages --cluster -o json` gives the instance name in `name` for installed rows and has no package field. An instance renamed with an alias does not match its package's records: an error, note, or security record for it does not apply, and its changed objects count as having no change record. Records of kind `silent` and records with `required-stop` apply to every project to stay safe. Look at `packages_in_use` and `plan::applies`.
