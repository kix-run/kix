# 2026-11-18 · `kix/packages/experimental/clickhouse-keeper` · `kix rollback` from Keeper 26.8 to 26.3 leaves replicas that will not start.

The 26.8 package sets `write_snapshot_version = 6` so Keeper 26.3 can read its snapshots. On rollback the operator writes the older settings, without that line, into the shared ConfigMap `chk-<name>-common-configd` before it restarts the replicas. Each 26.8 replica still running hot-reloads it, writes its next snapshot in format 8, and then fails on 26.3 with `Unsupported snapshot version 8`. On kind with `clusters/test-clickhouse.nix`, two of three replicas failed. Each one started after its newest snapshot was moved aside, with no data lost. The setting cannot stay in the old package, because Keeper 26.3 refuses to start on the unknown setting. Kix has no way to remove a setting only after an image change has rolled out.
