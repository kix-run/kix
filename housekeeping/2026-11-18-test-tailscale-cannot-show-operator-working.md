# 2026-11-18 · `clusters/test-tailscale` · The test cluster cannot show the tailscale operator doing any work.

Without a real OAuth client, the operator exits at startup with `401 Unauthorized` from the Tailscale API, so `kix deploy tailscale` always fails at `Deployment/tailscale`. The 8 objects after it are never applied: the Ingress, the LoadBalancer Service, the ServiceMonitor, and the PackageInstance. A version bump can show only that the new image runs, that the CRDs accept and keep resources, and that the egress policy lets the operator reach the API. It cannot show that proxies start or that traffic reaches the backend. A dev tailnet credential in `clusters/dev-secrets/`, or a control server run in the cluster through `env.OPERATOR_LOGIN_SERVER`, would close this gap.
