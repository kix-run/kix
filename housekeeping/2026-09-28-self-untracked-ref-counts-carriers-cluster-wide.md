# 2026-09-28 · `kix/lib/eval/cluster.nix` · Two instances with the same `by = "self"` name are listed by the untracked-reference audit and cannot fix it.

A `kix.untrackedRef { name; by = "self"; }` names its creator only when exactly one resource in the cluster carries a self reference to that name (`externalRefNames`). The count is by name, not by namespace, because the marker records no namespace and a consumer in another namespace would otherwise pass as the creator. Two operators in different namespaces that mint a Secret of the same name, such as two `stackgres-operator` instances with the same instance name, are both listed by `architecture.untrackedReferences` at info severity, and the package has no way to clear the listing. A marker that recorded its creator's identity would remove the ambiguity.
