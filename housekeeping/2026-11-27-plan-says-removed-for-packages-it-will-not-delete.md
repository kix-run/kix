# 2026-11-27 · `cli/kix-cli/src/plan/render.rs` · The plan says a package is "removed" when the deploy deletes none of its objects.

A cluster held 66 objects that an earlier deploy had applied and a later deploy, run without `--prune`, had left behind. `kix plan` for the next deploy, also without `--prune`, printed `- envoy-gateway-controller 1.10.0 (21 removed, 8 kept)` and `Plan: 32 updated, 6 removed`. The same output ended with `Objects: 112 to write, 0 to delete` and `66 object(s) left the build, still on the cluster (run kix gc ... to delete them)`. The last two lines are right: the deploy deletes nothing. A reader who stops at the summary line believes the deploy removes a running gateway. `kix plan --read-only` on the same cluster lists the same objects only as left behind, so the two modes also disagree. The package lines and the `Plan:` line should say "left the build" when the plan holds no delete for the object.
