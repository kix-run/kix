# 2026-10-01 · `kix/packages/grafana` · grafana's admin login defaults to admin/admin, and a set password lands in the Nix store.

`adminPassword` is a string option with the default `"admin"`, and the package writes it into an inline Secret, so a stranger's Grafana starts with Grafana's well-known login, and any password set there sits in the cluster file and the store. The package only warns about the default. `admin.existingSecret` takes the name of a Secret as a string, with `""` meaning unset, so Kix sees no dependency on that Secret and checks none of its keys. A required credential dependency (keys such as `admin-user` and `admin-password`, read through `kix.checkSecretKeys`) would replace `adminUser`, `adminPassword`, and `admin.*`; the monitoring module would then need to wire one.
