# 2026-11-25 · `kix/lib/flavors/k3s.nix` · The k3s flavor says nothing enforces `NetworkPolicy`, but k3s runs a built-in policy controller.

The header comment in `kix/lib/flavors/k3s.nix` says "Flannel does not enforce NetworkPolicy", which makes a stock k3s cluster sound unable to enforce policies. In fact, k3s embeds a kube-router policy controller and runs it alongside Flannel unless the server starts with `--disable-network-policy` (https://docs.k3s.io/networking/networking-services). Because the `k3s` flavor declares no `network-policy-enforcer`, setting `networkPolicy.enable = true` fails on stock k3s unless you install Cilium. The header's instructions for replacing Flannel with Cilium also tell users to pass `--disable-network-policy` without warning that k3s leaves the controller's old iptables rules on every node after you add that flag.
