# 2026-09-28 · `kix/packages/stackgres-operator` · The `restapi.image` and `adminui.image` options can name a different release than the operator runs.

The StackGres operator starts the restapi and admin-ui Deployments itself, at its own version. The package reads `restapi.image.{repository,tag}` and `adminui.image.{repository,tag}` only to list them in `extraImages`, and both tags default to `"1.19.0"` apart from `operator.image.tag`. An instance that moves `operator.image.tag` leaves the image inventory naming 1.19.0. The options are plain `lib.mkOption` strings rather than `kix.options.image`, so they also cannot carry a digest. Either derive both entries from `operator.image.tag` (a package `config` with `lib.mkDefault` would do it) or drop the options and compute the inventory from the operator's tag.
