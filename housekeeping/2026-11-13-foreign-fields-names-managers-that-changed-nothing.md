# 2026-11-13 · `cli/kix/src/cluster/drift.rs` · Drift output names field managers that changed nothing, because Kix cannot tell which fields it lost.

`kix status` prints "ConfigMap kube-system/coredns changed since deploy (data by kubeadm, data.Corefile by kubectl-patch)". kubeadm changed nothing after the deploy. It owned `data` before Kix took the ConfigMap. `foreign_owners` lists every other manager, and `foreign_fields` (used by `kix plan` and `kix diff`) keeps every field Kix does not own now, so both include fields Kix never applied. The applied-hash stamp records a hash, not the fields Kix applied, so nothing on the live object says which fields Kix lost. Comparing each managedFields `time` with the record's `deployed_at` compares the API server's clock with the deploying machine's clock, so it is not a reliable rule either.
