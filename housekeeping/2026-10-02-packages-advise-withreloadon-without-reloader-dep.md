# 2026-10-02 · `kix/packages/{external-dns,valkey}` · A rotated secret-ref Secret does not roll external-dns or valkey pods, and the how-to pages tell users to apply reloader's `withReloadOn`, which they cannot.

`withReloadOn` transforms Deployment or StatefulSet builder args inside a package build, before `scope.mkDeployment`. A cluster author cannot apply it to a package's workload from a cluster file, so `publish-dns-records-with-external-dns.mdx` and `deploy-valkey-redis.mdx` describe a step nobody can take. Neither package takes a `reloader` dependency. harbor takes an optional `reloader ? null` dependency and applies `withReloadOn` itself for every secret dependency without `out.identityHash`.
