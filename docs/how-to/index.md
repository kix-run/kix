# How-to Guides

How-to guides are recipes for accomplishing specific tasks. They assume you already have a working kixpkgs setup and understand the basics.

| Guide | What it covers |
|-------|---------------|
| [Import Existing Resources](import-existing-resources.md) | Reference services already running in the cluster without managing them |
| [Migrate a Service to kix](migrate-service.md) | Move an existing Helm/Ansible-managed service into a kix package |
| [Manage Secrets with SOPS](manage-secrets.md) | Create, encrypt, and deploy secrets via SOPS |
