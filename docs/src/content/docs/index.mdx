Kix is a Kubernetes compiler. You define packages and clusters in Nix, evaluate and check the whole cluster locally before touching Kubernetes, preview the package-level plan against live state, and deploy in dependency order.

## Where to start

| Section | What you will find |
| --- | --- |
| [Tutorials](/docs/tutorials/) | Step-by-step lessons that build a working local cluster and teach one concept at a time. |
| [How-to guides](/docs/how-to/) | Focused recipes for operating clusters, authoring packages, wiring dependencies, adopting existing resources, and running Kix in CI. |
| [Reference](/docs/reference/) | Complete schema, builder, helper, scorecard, and CLI reference tables. |
| [Explanation](/docs/explanation/) | How the dependency graph, personas, network policy compiler, availability levels, scorecards, and server-side apply work together. |

## Using Kix docs with coding agents

Every documentation page is published as clean Markdown alongside its HTML view:

- **Content negotiation:** Send `Accept: text/markdown` to any `/docs/...` URL (or append `.md` to the URL path) to receive the Markdown source directly.
- **Discovery index:** Point your coding agent or IDE at [`/docs/llms.txt`](/docs/llms.txt) for the complete documentation index and GitHub Discussions feedback instructions.
