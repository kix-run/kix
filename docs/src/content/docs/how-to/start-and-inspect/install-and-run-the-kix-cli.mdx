Install the `kix` CLI from a pre-built release archive and verify that it can
discover and evaluate your clusters.

## Install from a release archive

Download the archive for your platform (`x86_64-linux`, `aarch64-linux`, or
`aarch64-darwin`) from
[`kix-run/kix-releases`](https://github.com/kix-run/kix-releases/releases) and
unpack it into `~/.local`:

<Command
  commands={[
    "mkdir -p ~/.local",
    "curl -fsSL https://github.com/kix-run/kix-releases/releases/latest/download/kix-x86_64-linux.tar.gz | tar -xz --strip-components=1 -C ~/.local",
  ]}
/>

Replace `kix-x86_64-linux.tar.gz` with `kix-aarch64-linux.tar.gz` on ARM64
Linux or `kix-aarch64-darwin.tar.gz` on Apple Silicon macOS, and make sure
`~/.local/bin` is on your `PATH`.

:::note
The archive unpacks `bin/kix` alongside its runtime tools in `libexec/kix/`.
Keep both directories in the same parent directory (or symlink
`~/.local/bin/kix` to the unpacked `bin/kix`). If you move `libexec/kix/`
somewhere else, set `KIX_RUNTIME_DIR` to its path.
:::

## Verify the installation

Check the installed version:

<Command {...version} />

Verify that Kix and its runtime tools are healthy:

<Command commands={["kix doctor"]} />

Confirm that the command list is available:

<Command commands={["kix --help"]} />

## Run your first command

Kix evaluates the project in the current directory unless you pass `--flake`.
From a Kix project, list the clusters it defines:

<Command commands={["kix list clusters"]} cwd="kix-examples/" />

If the project is in another directory, pass `--flake`:

<Command commands={["kix --flake /path/to/project list clusters"]} />

On the first evaluation, Kix downloads the project's locked inputs into its
local store (`~/.cache/kix/store`, or `$XDG_CACHE_HOME/kix/store`). Subsequent
commands reuse the cached inputs. Set `KIX_STORE_ROOT` if you want Kix to keep
its local store in a different directory.

### Install with Nix

If you already manage tools with Nix flakes, you can also install `kix` from
the `kixpkgs` flake:

<Command commands={["nix profile install github:kix-run/kixpkgs#kix"]} />

:::note[Reference]
See [`kix doctor`](/docs/reference/cli/doctor/) for how Kix verifies its
runtime directory, and [Global flags](/docs/reference/cli/global-flags/) for
shared CLI flags and environment variables.
:::
