---
title: "`package`"
description: "The package definition evaluated for an instance."
---

```nix
instances.apps.web.package = packages.web;
```

`package` selects the package that an instance evaluates. It is required for
every managed instance.

## Schema

| Property | Value |
|---|---|
| Type | raw Nix value |
| Default | none |
| Set at | `instances.<namespace>.<name>.package` |

The value is normally a package function:

```nix
{ scope, lib, kix, ... }:
{
  meta.version = "1.0.0";
  options = { /* ... */ };
  build = { self, config, ... }: { /* ... */ };
}
```

Kix also accepts an already evaluated package attribute set containing
`build`. Imports created with `kix.mkImport` use the same instance field but
follow the import evaluation path.

The module type is intentionally raw. Kix evaluates the package through its
own fixed point after cluster modules have finished merging. Two cluster
modules cannot supply different package values for the same instance without
resolving the module conflict.

The instance name and namespace do not need to match the package's attribute
name. They determine resource naming and dependency-resolution context for
this particular evaluation.
