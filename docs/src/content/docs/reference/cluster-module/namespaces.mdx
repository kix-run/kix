title: "`namespaces`"
description: "Configure Namespace metadata, quotas, network policies, and Pod Security Admission."
---

Kix creates a Namespace resource for each namespace used by an instance. Add a
`namespaces.<name>` entry to configure that resource or to create a namespace
before it contains an instance.

```nix
namespaces.apps = {
  labels.owner = "application-team";
  annotations."example.com/contact" = "on-call@example.com";
  podSecurity = "restricted";
  resourceQuota = {
    requests.cpu = "4";
    requests.memory = "8Gi";
  };
  networkPolicies.default-deny = {
    podSelector = { };
    policyTypes = [ "Ingress" "Egress" ];
  };
};
```

| Field | Type | Default | Effect |
|---|---|---|---|
| `labels` | attribute set of strings | `{ }` | Additional Namespace labels. Kix also writes `kubernetes.io/metadata.name` and `app.kubernetes.io/managed-by`. |
| `annotations` | attribute set of strings | `{ }` | Namespace annotations. |
| `resourceQuota` | `null` or attribute set | `null` | Creates `ResourceQuota/<namespace>-quota` with this value as `spec.hard`. The build fails if the namespace's workloads exceed the quota; see [Quota check](#quota-check). |
| `networkPolicies` | attribute set | `{ }` | Creates one Kubernetes NetworkPolicy per entry, named `<namespace>-<entry>`, with the entry value as `spec`. |
| `podSecurity` | `null`, `privileged`, `baseline`, or `restricted` | `null` | Sets the `pod-security.kubernetes.io/enforce` label. |

Package metadata also contributes to Pod Security Admission. Kix takes the
most permissive `meta.podSecurity` requested by an instance in the namespace.
An explicitly configured namespace level that is stricter than a package
requires is an evaluation error. When package declarations exist, their most
permissive value is rendered; a more permissive namespace value does not
raise it further.

The `networkPolicies` field writes standard Kubernetes NetworkPolicy objects
directly. It is separate from `cluster.networkPolicy`, which derives policies
from package dependencies through the configured policy provider.

See [`meta.podSecurity`](/docs/reference/package-schema/meta/#podsecurity) for the package
declaration.

## Quota check

Kubernetes enforces a ResourceQuota when objects are created at runtime. Kix
checks quotas at build time and fails the build when the least a namespace's
workloads use is more than any of its quotas allow.

Kix counts built-in workloads by their pods:

| Kind | Minimum pod count |
| --- | --- |
| Pod | 1 pod. |
| Deployment, ReplicaSet, StatefulSet, ReplicationController | `spec.replicas` pods, or the `minReplicas` (default 1) of a HorizontalPodAutoscaler targeting the workload. |
| Job | `spec.parallelism` pods, capped by `spec.completions` when set. A Job with `spec.suspend: true` counts as 0 pods. |

Each pod counts the sum of its regular containers' requests and limits. If a
container sets a limit without a request, the limit is also used as the
request (matching Kubernetes' default). Init containers are excluded so the
computed usage never exceeds what Kubernetes charges.

A custom resource counts when its CRD declares
[`usesAtLeast`](/docs/reference/scope-helpers/crds-and-crd-refs/). That
function returns the least the operator always uses for the custom resource,
keyed like a quota: pods and their requests and limits, and also storage
claims, Services, or object counts where the operator always makes them.

Kix checks `namespaces.<name>.resourceQuota`, the quota imported from a
consumer's platform interface, and any unscoped `ResourceQuota` rendered by an
instance in the namespace (quotas with `scopes` or `scopeSelector` are
skipped). It compares every key a quota sets, and maps the shorthand keys
`cpu`, `memory`, and `ephemeral-storage` to `requests.*`. A key nothing
reports counts as 0. Built-in workloads report only pods, requests, and
limits, so a storage or object-count quota is checked only against what
custom resources declare.

DaemonSets, CronJobs, and custom resources without `usesAtLeast` are not
counted. When a quota check fails, the error message lists those resources
under `Not counted` so you can see what was excluded from the total.
