---
title: "`autoNamespace`"
description: "The default namespace for instances created from the package catalog."
---

```nix
autoNamespace = "platform";
```

`autoNamespace` sets the default namespace for instances that Kix creates
from `availablePackages`.

## Schema

| Property | Value |
|---|---|
| Type | null or string |
| Default | `null` |

Kix chooses an auto-instantiated package's namespace in this order:

1. `availablePackages.<name>.namespace`, when set;
2. `autoNamespace`, when set; or
3. the namespace of the instance that first demanded the package.

`autoNamespace` affects catalog entries only. It does not move explicit
instances, imports, or optional instances.

When several consumers need a package that represents a cluster-wide role,
Kix creates one shared role provider rather than one per consumer namespace.
Setting `autoNamespace` gives that provider a predictable home. For ordinary
dependency names, namespace remains part of the demand when no fixed or
automatic namespace is configured. A package that runs once per cluster and
is needed from two namespaces is then refused, so set `autoNamespace` or
declare the package once.
