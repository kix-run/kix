---
title: "`compatibleWith`"
description: Version ranges a package declares for its dependencies.
---

`meta.compatibleWith.<dep>` declares a version range for the dependency
bound to `<dep>`, with optional `minVersion`, `maxVersion`, and `reason`.
`meta.k8s.minVersion` and `maxVersion` declare a range for the cluster's
`k8sVersion`. Versions follow the [version grammar](/docs/reference/meta/version/).

A constraint compares at its own precision. `maxVersion = "1.30"` accepts
`1.30.4` and rejects `1.31.0`; `minVersion = "1.30"` accepts `1.30.0-rc.1`,
because the prerelease is below the constraint's precision.

| Outcome | Result |
|---|---|
| The version is inside the range | Passes |
| The version is outside the range | Failed assertion naming the dependency, both versions, and the `reason` |
| The constraint is not a version (`minVersion = "abc"`) | Failed assertion |
| The dependency reports no version, a word such as `"external"`, or a version less precise than the constraint (`"1.31"` against `minVersion = "1.31.2"`) | Warning; Kix skips the check |

An unset `k8sVersion` is not checked and does not warn.

A managed dependency reports its package's `meta.version`; an import
reports `out.version` if it sets one.
