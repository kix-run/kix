---
title: "Tutorials"
description: "Learn Kix by working through a sequence of small, runnable examples."
---

The tutorials are the guided path through Kix. Follow them in order: each one
adds one new idea, and later tutorials assume you understand the pieces that
came before.

Most tutorials are tied to the runnable examples in
[`kix-examples`](https://github.com/kix-ops/kix-examples). You will start by
running a tiny `hello-world` cluster, then read the files that made it work,
then build up toward local packages, dependency wiring, typed options,
reusable packages, and compile-time policy.

The examples are deliberately small. They are not meant to show every possible
production choice at once; they are stepping stones. Keep the example repo open
while you read, run the commands as you go, and treat each tutorial as one
brick in the larger model.

When you already know the concept and just need a task recipe, use the
[how-to guides](/docs/how-to/). When you need exact fields, flags, or schemas, use
the [reference](/docs/reference/). When you want the design reasoning, use the
[explanation pages](/docs/explanation/).
